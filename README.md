# web-agent

`web-agent` is a web agent made using Flask and HTML/CSS/JS
that runs locally on a server and uses Gemini.
 
## Installation
 
1. Clone this repository
    ```bash
    git clone https://github.com/Pjdur/web-agent.git
    ```
    
2. Go to http://localhost:5000 and click "API Key" then enter
   your Gemini API key.
